# Metrics

The framework uses standardized metrics to characterize both computational
performance and efficiency.

## Accuracy

Measures the task-specific quality of the result.

## Latency

Measures the time required to process a defined workload.

## Throughput

Measures the amount of workload processed per unit of time.

## Energy

Measures the energy required to execute the benchmark.

## Power

Measures the power consumed during execution.

## Memory

Measures the memory required by the benchmark.

The precise measurement methodology for each metric will be specified by the
framework.
