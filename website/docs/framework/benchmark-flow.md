# Benchmark Workflow

Every benchmark should follow a standardized execution procedure.

## 1. Define the workload

Specify the task, dataset, model, and input characteristics.

## 2. Configure the system

Document the hardware, software, compiler, runtime, and relevant parameters.

## 3. Execute the benchmark

Run the workload according to the framework's standardized procedure.

## 4. Measure performance

Collect the required metrics using the prescribed measurement methodology.

## 5. Validate the result

Verify that the result satisfies the framework's correctness requirements.

## 6. Store the result

Benchmark results will be stored in the central benchmark database together
with sufficient metadata to reproduce the experiment.
