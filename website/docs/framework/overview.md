# Framework Overview

The Neuromorphic Benchmark Framework defines a standardized methodology for
evaluating neuromorphic computing systems.

The framework is designed to enable meaningful comparisons across different
hardware platforms, software environments, models, and workloads.

## Goals

The framework aims to provide:

- Reproducible benchmark procedures
- Clearly defined evaluation metrics
- Hardware-independent benchmark specifications
- Transparent measurement methodology
- Machine-readable benchmark results
- A centralized benchmark database

A benchmark follows the general workflow:

Dataset
