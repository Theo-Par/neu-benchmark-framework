# Hardware

The Neuromorphic Benchmark Framework supports standardized benchmarking
across neuromorphic and conventional computing platforms.

## Supported platforms

The framework will provide hardware-specific benchmarking guides for each
supported platform.

These guides will describe:

- Hardware requirements
- Software requirements
- Installation
- Benchmark configuration
- Execution procedure
- Measurement methodology
- Result validation
- Reproducibility requirements

## Platforms

Detailed platform documentation will be added as the framework develops.

### Neuromorphic systems

- Intel Loihi 2
- SpiNNaker
- BrainScaleS
- Other neuromorphic platforms

### Conventional accelerators

- GPU
- FPGA
- CPU

### Custom systems

Custom neuromorphic architectures can also be documented using the framework's
standard benchmark specification.
