# Introduction

Welcome to the **Neuromorphic Benchmarking Framework Webpage**.

This project provides a standardized framework for evaluating and comparing
neuromorphic computing systems.

## What is this framework?

Neuromorphic computing systems differ substantially in their hardware
architecture, programming models, execution characteristics, and measurement
methodologies.

This framework provides standardized procedures for evaluating these systems
using consistent benchmark definitions and metrics.

## What can you find here?

### Framework

Learn about the principles behind the benchmarking methodology, including
benchmark definitions, metrics, measurement procedures, and reproducibility.

### Hardware

Find detailed instructions for running the benchmarks on different
neuromorphic and conventional computing platforms.

### Benchmarks

Explore benchmark definitions and, eventually, results collected from
different systems.

### Publication

Read the publication describing the framework and find citation information
and supplementary resources.
